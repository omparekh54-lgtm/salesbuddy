# SalesBuddy AI Prototype

Interactive static prototype of the SalesBuddy AI product experience.

## Local preview

Open `index.html` directly in a modern browser or serve this directory with any static HTTP server.

## Deployment

The repository is configured as a static Vercel site. No build command or environment variables are required for this prototype.

> This is a front-end prototype with demo data. Buttons and workflows simulate the intended product experience; no live CRM, messaging, payment, or AI backend is connected yet.
